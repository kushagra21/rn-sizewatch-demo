# rn-sizewatch demo

A plain React Native 0.83.6 app (from the community CLI template) used to try [rn-sizewatch](https://github.com/kushagra21/rn-sizewatch), the bundle size bot for React Native. Each pull request here gets a comment saying how the JS bundle, Hermes bytecode and assets changed, and why.

The workflow is in [.github/workflows/size.yml](.github/workflows/size.yml) and the budgets in [sizewatch.config.json](sizewatch.config.json).
